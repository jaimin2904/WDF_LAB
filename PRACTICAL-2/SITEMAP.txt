PAGE DETAILS
============

1. login.HTML (Login Page)
   - Role: Entry point / authentication
   - Links to: home.HTML (form submit), signup.HTML (signup button)
   - Has Navigation Bar: No

2. signup.HTML (Student Signup)
   - Role: New student registration
   - Links to: home.HTML (form submit), login.HTML (back button)
   - Has Navigation Bar: No

3. home.HTML (Main Dashboard)
   - Role: Central hub / landing page after login
   - Links to: home.HTML, profile.HTML, events.HTML, Attendance.HTML,
              result.HTML, login.HTML (logout)
   - Has Navigation Bar: Yes (Home, Profile, Events, Attendance, Result, Logout)
   - External Links: charusat.ac.in, Instagram, Charusat logo

4. profile.HTML (Student Profile)
   - Role: Display student personal information
   - Links to: home.HTML, profile.HTML, events.HTML, Attendance.HTML,
              result.HTML, home.HTML (back)
   - Has Navigation Bar: Yes (Home, Profile, Events, Attendance, Result)
   - Static Data: Name, ID, Department, Semester, Email, Phone

5. events.HTML (Upcoming Events)
   - Role: Display upcoming college events
   - Links to: home.HTML, profile.HTML, events.HTML, Attendance.HTML,
              result.HTML, register.HTML (register button), home.HTML (back)
   - Has Navigation Bar: Yes (Home, Profile, Events, Attendance, Result)
   - Events Listed:
     - Coding Competition - 12 August 2026 - Computer Lab
     - Sports Day - 20 August 2026 - College Ground

6. register.HTML (Event Registration)
   - Role: Register for upcoming events
   - Links to: home.HTML, profile.HTML, events.HTML, Attendance.HTML,
              result.HTML, home.HTML (submit/back)
   - Has Navigation Bar: Yes (Home, Profile, Events, Attendance, Result)
   - Accessible From: events.HTML only (Register button)

7. Attendance.HTML (Attendance Record)
   - Role: Display student attendance by subject
   - Links to: home.HTML, profile.HTML, events.HTML, Attendance.HTML,
              result.HTML, home.HTML (back)
   - Has Navigation Bar: Yes (Home, Profile, Events, Attendance, Result)
   - Subjects: C Programming (95%), Java (91%), DSA (93%), CN (96%)
   - Overall Attendance: 94%

8. result.HTML (Exam Results)
   - Role: Display student exam results and grades
   - Links to: home.HTML, profile.HTML, events.HTML, Attendance.HTML,
              result.HTML, home.HTML (back)
   - Has Navigation Bar: Yes (Home, Profile, Events, Attendance, Result)
   - Subjects: JAVA (A+), DSA (A+), C++ (A+), FCN (A+)
   - SGPA: 9.99, CGPA: 9.99, Grade: A+

NAVIGATION FLOW SUMMARY
========================

Pre-Auth Pages (No Nav Bar):
  - login.HTML --> signup.HTML (signup)
  - signup.HTML --> login.HTML (back)

Post-Auth Pages (With Nav Bar):
  - home.HTML     --> profile, events, attendance, result, login (logout)
  - profile.HTML  --> home (back)
  - events.HTML   --> register, home (back)
  - register.HTML --> home (submit/back)
  - Attendance.HTML --> home (back)
  - result.HTML   --> home (back)

KEY OBSERVATIONS
================

1. login.HTML is the entry point of the application
2. Login form submits directly to home.HTML (no real authentication)
3. Logout is handled by linking back to login.HTML
4. Navigation bar is consistent across all post-auth pages
5. login.HTML and signup.HTML do NOT have navigation bars
6. register.HTML is only reachable from events.HTML
7. All "BACK" buttons return to home.HTML
8. All form submissions redirect to home.HTML
9. Profile and Result pages display static/hardcoded student data
10. External links on home page: charusat.ac.in, Instagram
